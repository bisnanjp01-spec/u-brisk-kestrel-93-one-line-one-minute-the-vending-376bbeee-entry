One pickup line, spoken by a vending machine to a passing human: a coil with a crush, dropping everything the second you walk by. Entry for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" — a single line of at most 200 characters, judged on machine voice, the machine's own world of coils and snacks, a punch that lands in the last few words, and charm over creepiness.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Node 22, standard library only, no network, no input.
